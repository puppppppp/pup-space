# ชีตข้อมูล: ชีวิตนักศึกษาแพทย์ไทย

ใช้เป็นข้อมูลประกอบการเขียนนิยาย ทุกข้อติดป้ายไว้ว่าเชื่อถือได้แค่ไหน:
- ✅ = มีแหล่งอ้างอิง (ดูท้ายไฟล์)
- 💡 = ความรู้ทั่วไปที่คนในวงการใช้กัน แต่ยังไม่ได้ตรวจกับแหล่งทางการ ควรถามคนที่เรียนหมอจริงก่อนใช้ในฉากสำคัญ

แต่ละมหาวิทยาลัยมีรายละเอียดต่างกัน ถ้าในเรื่องไม่ระบุชื่อมหาลัยจริง จะเขียนยืดหยุ่นได้มากกว่า

---

## 1. หลักสูตร 6 ปี

| ปี | ช่วง | เรียนอะไร / ชีวิตเป็นยังไง |
|---|---|---|
| 1 | ปรีคลินิก | วิทยาศาสตร์พื้นฐาน ✅ ยังเหมือนเด็กมหาลัยทั่วไป มีรับน้อง กีฬาคณะ 💡 |
| 2 | ปรีคลินิก | เรียนร่างกายมนุษย์ทีละระบบ ✅ เริ่มเรียนกายวิภาค (Anatomy) กับ **อาจารย์ใหญ่** ✅ |
| 3 | ปรีคลินิก | เรียนระบบร่างกายและพยาธิวิทยาต่อ สอบ **NL1** (วิทยาศาสตร์การแพทย์พื้นฐาน) ✅ |
| 4 | คลินิก | เริ่ม **ขึ้นวอร์ด** ✅ หมุนไปตามภาควิชา เช่น อายุรกรรม ศัลยกรรม เด็ก สูติ 💡 |
| 5 | คลินิก | หมุนวอร์ดต่อ สอบ **NL2** (วิทยาศาสตร์การแพทย์คลินิก) ✅ |
| 6 | คลินิก | เรียกกันว่า **"เอ็กซ์เทิร์น" (extern)** 💡 ทำงานใกล้เคียงหมอจริง อยู่เวร รับปรึกษาร่วมกับแพทย์ฝึกหัด ✅ สอบทักษะและหัตถการทางคลินิก ซึ่งนับเป็น **NL3** ✅ |

> ✅ ตัวอย่างข้างบนอ้างอิงศิริราช ส่วนคณะอื่นปีที่สอบ NL ใกล้เคียงกัน (ข้อมูลขอนแก่นสอดคล้อง)

## 2. หลังเรียนจบ

- **อินเทิร์น / แพทย์เพิ่มพูนทักษะ:** ปีแรกหลังจบ ทำงานในโรงพยาบาลที่แพทยสภารับรอง ✅ (โครงการเริ่มตั้งแต่ พ.ศ. 2538)
- **ชดใช้ทุน 3 ปี:** ทำงานรับราชการตามสัญญา ✅ มีระบบ**จับฉลาก**เลือกสถานที่ทำงานผ่าน กสพท. ✅ แต่ข้อมูลที่หาได้ค่อนข้างเก่า รายละเอียดปัจจุบันควรเช็กอีกครั้ง
- **โครงการแพทย์ชนบท (CPIRD):** เรียนแบบผูกพันกับโรงพยาบาลในภูมิภาค เริ่ม พ.ศ. 2537 ✅ ใช้เป็นปมได้ เช่น ตัวละครถูกผูกไว้กับจังหวัดหนึ่ง แต่คนรักจับฉลากได้อีกที่
- **เรียนต่อเฉพาะทาง:** แพทย์ประจำบ้าน (resident) แล้วเป็นอาจารย์หรือหมอประจำ (staff) 💡

## 3. อาจารย์ใหญ่ (ใช้กับพล็อต 1)

- "อาจารย์ใหญ่" คือร่างผู้อุทิศร่างกายเพื่อการศึกษา ✅
- นักศึกษาแพทย์**ปี 2** ร่วม**พิธีขอขมา** (จุฬาฯ เรียกว่า "พิธีอาจาริยปูชา") ก่อนเริ่มเรียน ✅
- มีทำบุญตักบาตรอุทิศส่วนกุศล ✅ เมื่อเรียนจบจึงมี**พิธีพระราชทานเพลิงศพ** ✅
- มีงานวิจัยเรื่องความรู้สึกของนักศึกษาแพทย์ต่อการผ่าร่างอาจารย์ใหญ่ ✅ เป็นวัตถุดิบดีมากสำหรับฉากที่ตัวละครเปิดใจ
- 💡 ธรรมเนียมที่มักได้ยิน: ศึกษาประวัติอาจารย์ใหญ่ เขียนจดหมายถึงท่าน ไหว้ก่อนและหลังเรียน (ควรถามคนจริงก่อนใช้)

## 4. ชีวิตในวอร์ดและเวร (ใช้กับพล็อต 2 และ 3)

- **วอร์ดราวด์ (ward round):** เป็นหัวใจของการเรียนชั้นคลินิก อาจารย์และแพทย์ประจำบ้านสอนข้างเตียงผู้ป่วย ✅
- **เวรดึกยาวมาก:** แพทย์โรงพยาบาลรัฐบางคนทำงาน 8 ชั่วโมง ต่อเวร 24 ชั่วโมง แล้วทำต่ออีก 8 ชั่วโมง ✅ บางแหล่งบอกว่ารวมแล้วราว 80 ชั่วโมงต่อสัปดาห์ จนหมดไฟและซึมเศร้า ✅
- **ง่วงหลังลงเวร:** เคยมีอินเทิร์นเสียชีวิตจากอุบัติเหตุหลังลงเวร แพทยสภาจึงเตือนให้เลี่ยงขับรถตอนง่วง ✅
  → ใช้เป็นฉากห่วงใยได้ เช่น ตัวเอกไม่ยอมให้อีกฝ่ายขับรถกลับเองหลังเวรดึก (ควรเขียนอย่างระวัง เพราะอ้างอิงจากเหตุการณ์จริง)
- **ราวด์กลางคืน:** เวรวันหยุดบางที่ราวด์ตอน 2 ทุ่ม และใช้เวลาเกือบ 3 ชั่วโมง ✅ (มาจากบล็อกส่วนตัวของหมอ)

### ศัพท์ที่ใช้กันจริง 💡
| คำ | ความหมาย | ใช้ในเรื่องยังไง |
|---|---|---|
| อยู่เวร / ลงเวร / ส่งเวร | ทำงานนอกเวลา / ออกเวร / ส่งต่องานให้เวรถัดไป | จังหวะพบกันกับแยกจากกัน |
| พรีราวด์ | ดูคนไข้ก่อนอาจารย์มาราวด์ | ฉากเช้ามืด เจอกันก่อนใคร |
| รับเคส / ซักประวัติ | รับผู้ป่วยใหม่ / ถามประวัติ | ฉากทำงานคู่กัน |
| staff / resident / intern / extern | อาจารย์ / แพทย์ประจำบ้าน / แพทย์ฝึกหัด / นศพ.ปี 6 | ลำดับอาวุโสที่สร้างความตึงเครียดได้ |
| consult | ขอความเห็นจากแผนกอื่น | ข้ออ้างให้ได้เจอกัน |
| admit / D/C | รับนอนโรงพยาบาล / ให้กลับบ้าน | |
| OPD / IPD / ER / OR | ผู้ป่วยนอก / ผู้ป่วยใน / ห้องฉุกเฉิน / ห้องผ่าตัด | |
| Code Blue / CPR | เรียกทีมกู้ชีพ / ปั๊มหัวใจ | ไคลแมกซ์ของพล็อต 3 |
| ตามแล็บ / ตามฟิล์ม | ไปดูผลเลือดหรือผล X-ray | มุกวิ่งวุ่น |
| long case / short case | เคสที่ใช้สอบหรือนำเสนอ | ฉากกดดันก่อนสอบ |
| morning report / topic | ประชุมเคสตอนเช้า / นำเสนอหัวข้อ | ฉากต่อหน้าอาจารย์ |

### มุกจากศัพท์อาชีพ (แบบ "คัทครับ" ของ der_August17) 💡
- "ส่งเวรครับ" แปลว่าขอตัวไปก่อน หรือฝากอีกฝ่ายดูแลต่อ
- "ขอ consult หน่อย" ใช้เปิดบทสนทนากับคนที่แอบชอบ
- "ชีพจรเกินร้อย" ใช้บอกว่าใจเต้นแรง
- "ขอ admit ได้ไหม" ใช้ขอนอนค้างที่ห้อง
- "D/C ได้แล้ว" ใช้ไล่ให้กลับบ้าน แบบงอน ๆ

## 5. ชีวิตนอกห้องเรียน 💡
- **สายรหัส:** รุ่นพี่กับรุ่นน้องที่จับคู่ตามเลขรหัส ส่งต่อชีท ข้อสอบเก่า และของขวัญกันเป็นทอด ๆ
- **รับน้อง / กีฬาคณะ / ประกวดดาวเดือน:** ใช้เป็นฉากเปิดตัวละครตอนต้นเรื่อง
- **ชีท / ข้อสอบเก่า (โพย):** ของมีค่าในคณะ ใช้เป็นปมได้ เช่น คดีทุจริตข้อสอบในพล็อต 3
- **ห้องสมุดหรือห้องอ่านหนังสือ 24 ชั่วโมงช่วงสอบ:** ฉากติวด้วยกันตอนดึก
- ⚠️ เรื่องปี 1 เรียนที่ไหน (เช่น ศาลายาหรือในเมือง) ต่างกันในแต่ละมหาลัย ยังหาข้อมูลยืนยันไม่ได้
